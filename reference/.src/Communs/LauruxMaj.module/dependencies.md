## Notes d'analyse
- **Seul appelant** : `Fmenu.Form_Open` ([Fmenu.class:189](../../../../.src/Communs/Fmenu.class#L189)), juste après `Majversion.RecupVersion()`
  qui alimente `Majversion.Version` (lu par les blocs 3.60 et 3.61). Vérifié par `grep` : aucun autre
  appel ; `FRestore.Verif_Version` ([FRestore.class:Verif_Version](../../../../.src/Communs/FRestore.class#L178-L211)) est un homonyme local sans lien.
  Le mode caisse (`Cmenu`, `-p`) n'appelle jamais ce module.
- **Portée réductible annoncée par deps.py** (109 `MajXXX`) : exacte (appels internes au dispatcher
  seulement), mais sans objet : les migrations sont figées par consigne. 12 fonctions (`Maj40` à
  `Maj46`, `Maj50`, `Maj201`, `Maj202`, `Maj203`, `Maj205`) ne sont appelées nulle part, même en interne.
- **Tables** : la liste AUTO est fiable pour les noms écrits en dur (les migrations n'utilisent
  `Cbase.Table` que 14 fois). Elle **rate** les tables construites dynamiquement :
  `"Fiches_EntTickets" & code`, `Fiches_Reglts<XX>`, `Fiches_LigTickets<XX>`, `Fiches_Ticketx<XX>`,
  `Fiches_Ticketz<XX>` (par caisse), `"Fiches_Mvt" & $i` / `MvtM` / `MvtA` (boucles 1 à 5),
  `Fiches_Cpostaux0<i>`, les tables suffixées `& Soc` du pattern historique, et **toutes** les tables
  de la base via `information_schema` / `show tables` (`Maj311`, `Maj369`). `Corjxs` et
  `Fiches_ligregie` (option bois) ne sont pas dans `db_control.csv`.
- **Appels externes non SQL** : `Shell mysql` (`Maj310`, `Maj311`), `Shell mysqldump` (`Maj369`),
  `Shell xdg-open` (épilogue) ; fichiers `~/tmp/tables.txt`, `~/SauveV368/`, `CV.txt`,
  `~/.config/gambas3/Laurux3.conf` (`Maj368`).
- **Dépendances implicites** : `Majversion` est un formulaire utilisé par son auto-instance ;
  `DB_Connection.Exec` réécrit le SQL sous SQLite mais ne traduit pas `SET NAMES` (prologue).
  `Utils.db.AutoIncrement()`/`Engine()` sont utilisés par des migrations figées : toute modification de
  ces deux méthodes de [DB_Connection](../../Utils/DB_Connection.class/architecture.md) change le
  résultat d'un rejeu de migration.
- **Aucune dépendance circulaire.** Contrainte d'ordre : aucune (le module n'est pas reworké hors
  documentation) ; les reworks de `DB_Connection`, `LDate`, `LGed`, `ProgBar`, `Sha1Calc`,
  `Majversion` doivent repasser le test replay LAURUXMAJ-T01.
