## Notes d'analyse

### Ce que l'heuristique surestime ou rate (vérifié par grep)

- **Portée réductible, faux positifs** : `Application_Signal` est l'événement `Application` levé par
  l'interpréteur pour le module de démarrage ; `ReplayTimer_Timer` est le handler du `Timer`
  « ReplayTimer ». Les deux restent `Public`.
- **Portée réductible, confirmé** : `Lock`, `Lancement`, `Parse_Args`, `Start_Test`, `Coul` (aucun
  `Start.<nom>` hors du module) ; variables `Arg_Config_File`, `Arg_Test`, `Arg_Start_Societe`,
  `Arg_Restore_DB`, `hReplayTimer`, `Evens`, `Ev`, `Evc`, `Evl`.
- **Code mort, confirmé** : `Nstockes`, `Suspendus`, `StartDate`, `$cai` (aucun lecteur, y compris
  dans le module pour les trois premiers : écrits seulement) ; `Private hpb`, `hlb`.
- **`Start.Main`** : appelé par `Fsoc.Soclist_Click` (`Fsoc.class:625`), appel actif ; l'appel de
  `LauruxConf.class:465` est commenté.
- **Écrivains externes** (non distingués des lecteurs par `deps.py`) : `Societe` (`Fsoc`),
  `GlobalSettings` (`Fmenu`, `Prefs`), `Motdepasse` (`MDP`, `Fmenu`, `Fsoc`), `NoTips` (`Fmenu`),
  `$tcai` (`Ouverture`, `Fmenu`), `Success`/`Exit` (`Utils.Exit`), `Restart` (`LauruxConf`). Tableau
  complet lecteurs/écrivains dans [architecture.md](architecture.md#état-global).
- **Lecteur manqué** : `Start.$tcai` dans `Attrib.class:171` (argument d'un `Exec`) n'apparaît pas
  dans le tableau « Utilisé par » ; `Attrib` y figure pour `LocalSettings`/`Societe` seulement.
- **`Start.Caisse`** : lu par `TriHistos` uniquement ; ne pas confondre avec la classe `Caisse`.

### Appels dynamiques

- `Object.Call(Menu, "Show")` et `Object.GetProperty(Menu, "Window")` (l. 324-325) : `Menu` est
  un `Cmenu` ou un `Fmenu` (dépendance réelle vers les deux formulaires).
- `Class.Load("LPrix")`, `Class.Load("LScript")`, puis `Object.Call(obj, "Internal_Test", …)` sur
  toute classe chargée qui expose `Internal_Test` (l. 483-506) : dépendance de test vers `LPrix` et
  `LScript`, non visible comme appel statique.
- `ReplayObserver.Replay_Event` appelle à son tour des handlers `<Contrôle>_Click` par
  `Object.Call` (voir ReplayObserver).
- `Shell "ps -p " & Pids & " >/dev/null" Wait` (l. 173) : dépendance à `ps` (procps).
